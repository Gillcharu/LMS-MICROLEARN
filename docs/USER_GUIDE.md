# MicroLearn User Guide

## 1. Getting Started
1. Register as learner or creator.
2. Login and open Dashboard.
3. Start short lessons (5-15 minutes).

## 2. Learner Flow
1. Open Lessons and choose a lesson.
2. Read/watch content and mark progress.
3. Complete 3-5 quiz questions.
4. Check score and progress on Dashboard.

## 3. Learning Paths
1. Browse published paths.
2. Enroll in a path.
3. Create your own draft path from Paths page.

## 4. Gamification
1. Earn points for attempts and completions.
2. Keep daily streaks.
3. Unlock badges for milestones.

## 5. Social Features
1. Like lessons.
2. Comment on lessons.
3. Follow other users and view activity feed.

## 6. Creator Tools
1. Open Creator Studio.
2. Create lessons with duration 5-15 minutes.
3. Add exactly 3-5 quiz questions.
4. Create and publish learning paths.

## 7. Help
Use in-app Help page for FAQs and first-time tutorial.
